Papertalk files

A converted paper can travel as a .papertalk file: its record, script, mind map and voiced audio.

  • Export paper… saves one. Papertalk asks whether to include the PDF; most papers' PDFs are under copyright, so Export Without PDF is the default.
  • Bring one in with File → Import Paper… (⇧⌘O), by dropping it on the library, or by double-clicking it in Finder.
  • A paper whose id is already in your library comes in as a copy.

Where the library lives

Papers live in ~/Library/Application Support/papertalk/papers/, one package per paper (Finder shows each as a single item). Settings → General → Library folder moves it, for example into a folder you back up; papers already in that folder join the library.

One library on several Macs

Run the storage server that comes with Papertalk (./app.sh server in the source) on any Mac or Linux machine, then enter its address (http://<host>:9170) and token in Settings → Server Settings. Clearing the URL switches back to the library on this Mac.
