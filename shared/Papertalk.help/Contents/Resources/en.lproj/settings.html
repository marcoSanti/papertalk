Papertalk Help

Settings

Open Settings with Papertalk → Settings… (⌘,). Pages save when you click Save, and show “Saved”.

First-run setup

The first time, a short setup asks where the library lives, which LLM writes the episodes, and where the voices are made. Test connection checks the servers answer. You can skip it and change everything here later.

General

The interface language (it follows your Mac's language unless you pick one: English, Italian, Spanish, German or French) and the Library folder.

LLM Settings

Any OpenAI-compatible chat server writes the episodes: LM Studio, llama.cpp, Ollama behind Open WebUI, or a hosted API. Enter its LLM base URL, the API key source (none, typed, or an environment variable) and the Model (Refresh models asks the server). With a local LLM, nothing about your papers leaves your Mac.

Voices

Voices are made on this Mac with Kokoro on the Neural Engine, or by an OpenAI-compatible text-to-speech server. A server saves memory on 8 GB Macs. Enter its Server URL, API key and model, and Requests at a time (1 to 16).

Server Settings

An optional storage server for sharing the library between Macs. See Share papers.

Query Prompts

Edit any prompt sent to the LLM. This includes the Ask prompt used when you chat about a paper. Reply formats are added automatically, so an edit can't break an import. Restore prompt defaults undoes your edits.

Prompt Presets

Named instructions for the Custom depth when importing.

Clear Data

Erase library and settings… deletes every paper and resets all settings (voice models are kept). Delete voice models… frees their disk space; they download again when needed. This page also turns Ask after listening back on.

Keys and privacy

API keys are kept in your Mac's Keychain, never in the preferences file.
