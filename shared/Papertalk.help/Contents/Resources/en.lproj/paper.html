Papertalk Help

Work with a paper

These actions are in the paper's window (Details) and in its context menu (right-click it, or Control-click).

Ask

Ask AI (beside Details) or Ask… in the context menu opens a chat about the paper. See Ask a paper.

Audio

  • Regenerate audio re-voices the existing script.
  • Export audio… saves the episode as one M4A (AAC) file named after the paper. It carries the title, authors (as artist), year, the first page as cover art, and the affiliations, DOI and tags in the comment, so it shows well in Music or any podcast player.
  • Delete audio frees disk space and keeps the script and PDF.

PDF management

  • Rerun episode writes a new script from the PDF, asking for the depth (and length) again.
  • Create mind map or Redraw mind map. See Mind maps.
  • Refresh metadata and Edit metadata….
  • Open the PDF in Papertalk's own viewer.

Library

  • Mark as listened.
  • Move to Library files the paper in a library.
  • Show in Finder reveals the paper's package on disk.
  • Export paper… saves it as a .papertalk file. See Share papers.
  • Delete paper (or Delete in the library) removes it, after asking.

During an import

Stop conversion stops it; the script and the sections already voiced are kept. Try again carries on.

Activity log

Show activity log lists what Papertalk did for the paper. If you report a bug, include it.
