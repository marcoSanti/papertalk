Papertalk Help

Troubleshooting

macOS won't open Papertalk

The app is only ad-hoc signed. The first time, right-click Papertalk.app and choose Open.

An import fails or stops

Check the address, key and model in Settings → LLM Settings (Refresh models shows whether the server answers), then use Try again: it carries on from where it stopped. The paper's Activity log says what went wrong.

Papertalk quits while making voices

Now and then the speech library on the Mac uses far too much memory and macOS stops the app. Nothing is lost: the script is saved, and voicing picks up where it stopped. Until this upstream bug is fixed, voices on a server (Settings → Voices) avoid it.

No notifications

Notifications appear only while Papertalk is in the background. Allow them in System Settings → Notifications → Papertalk.

Free disk space

Delete audio on papers you've heard, or Delete voice models… in Settings → Clear Data.
