Papertalk Help

Keyboard shortcuts

KeysAction
Space or ReturnPlay or pause the selected paper
Arrow keysMove around the library grid
DeleteDelete the selected paper (after asking)
⌘OImport a PDF
⇧⌘OImport a Papertalk paper
⌘,Settings
EscClose a sheet or cancel
Media keysPlay/pause; next and previous line

Menus

  • Papertalk → Check for Updates… and Check for Dev Builds… ask GitHub for a newer version. A newer stable release can be installed right away with Install and Relaunch; a dev build opens its page. Papertalk can also check at startup (Settings → General).
  • Papertalk → Clear All Data… opens Settings → Clear Data.
  • File → Redraw All Mind Maps… redraws every map.
  • Help → Papertalk Help opens this guide; type in the Help menu's search field to search it.
