Papertalk Help

Import a paper

Papertalk turns a PDF into an episode: an interviewer talks with one of the paper's authors.

Start an import

  • Choose File → Import PDF… (⌘O), or click + in the toolbar.
  • Drag a PDF from Finder onto the library.

Choose the depth

DepthWhat you get
In-depthWalks through the method faithfully, as long as the paper needs.
SummaryStays high-level and fits the length you set (5 to 60 minutes).
CustomFollows your own instructions. Save as preset keeps them for later; manage presets in Settings → Prompt Presets.
Direct readSkips the LLM and reads the paper out as it is.

The sheet also asks which library the paper goes into (see Libraries), and you can turn on Write the episode in this language to have the script written in the app's language. That is experimental: the voices are English, so they read other languages with an accent.

Choose who speaks

Before writing, Papertalk proposes the cast. You can rename the speakers, pick which author is interviewed, set each one's gender and voice, and hear a sample. The Speaking pace slider plays a sample when you release it, and is remembered for the next import. Click Use these voices to go on, or Skip audio to write the script now and voice it later with Regenerate audio.

If the paper is already in your library

Papertalk checks every library for the same paper and asks whether to keep importing. Declining discards the new copy.

While it works

Progress shows at the bottom of the window, and you can keep listening to other episodes. When the window is in the background, a notification tells you when an episode is ready or needs you. Stop conversion (in the paper's context menu) stops it; Try again carries on from where it stopped.

The first episode voiced on this Mac downloads the voice models (about 120 MB), so it takes a little longer.
